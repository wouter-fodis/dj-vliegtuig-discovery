# DJ VLIEGTUIG DISCOVERY

Ontdek nieuwe muziek met de vliegtuigen boven je. Elk vliegtuig dat over je heen komt, brengt een artiest uit zijn land mee in het genre dat jij kiest: een fragment van 30 seconden, dan de volgende uit dat land, tot er een nieuw vliegtuig komt. Bewaar wat je goed vindt en luister verder in Spotify.

Zusje van [DJ VLIEGTUIG RADIO](https://fodis.nl/fly/). Geen login nodig. Bronnen: ADS-B (adsb.lol), MusicBrainz, iTunes.

Zie `CLAUDE.md` voor de technische overdracht.
